# 추천용 테마 체계 v1 초안

## 분석 범위

- 운영 도서 2,048권의 기존 `themes` 값
- 고유 표현 2,932개
- 상위 빈도 표현과 동의어·복합어·형식 태그의 혼재 여부

기존 값에는 `친구/우정/친구와의 우정`, `가족/가족애/가족의 사랑`, `상상/상상력/판타지`처럼 같은 의미가 분산되어 있었다. 반대로 `번역`, `그림책`, `반복`, `플랩북`처럼 추천 주제가 아닌 메타데이터와 형식도 테마에 섞여 있었다.

## 분류 원칙

1. 테마는 부모 가이드와 연계 놀이 생성에 사용하지 않는다.
2. 테마는 도서 추천과 아이 관심사 설명에만 사용한다.
3. 책 한 권에는 추천에 실제로 구별력이 있는 표준 테마를 최대 3개 자동 부여한다.
4. 세부 대상과 동의어는 표준 테마로 합친다. 예: `고양이 → 동물·생명`, `겨울 → 자연·계절`.
5. 책 형식·문체·메타데이터·주의 콘텐츠는 테마와 별도 차원으로 관리한다.

## 테마와 분리할 값

- 형식/장르: 그림책, 정보책, 전래동화, 동시, 글 없는 그림책
- 읽기 특징: 반복, 의성어·의태어, 플랩·조작, 찾기
- 세부 대상 태그: 고양이, 공룡, 토끼, 겨울, 크리스마스 등
- 콘텐츠 주의: 죽음·이별, 공포, 전쟁·재난, 질병·상실 등
- 메타데이터: 번역, 시리즈

이 값들은 이후 별도 필드로 보존하면 검색과 안전 필터에 활용할 수 있지만, 추천용 테마 점수에는 그대로 섞지 않는다.

## 자동·직접 선택 규칙

- 자동 관심사: 최근 90일의 읽기 기록을 기반으로 반응, 완독, 집중, 질문, 최신성을 합산해 상위 5개를 계산한다.
- 직접 선택: 위 26개 목록에서 최대 8개를 고른다. 텍스트 입력은 동의어를 표준 테마로 바꾼 뒤 저장한다.
- 중복: 자동 관심사와 직접 선택이 같으면 자동 관심사 한 개로만 표시하고 추천에도 한 번만 반영한다.
- 우선순위: 직접 선택은 사용자의 명시적 신호이므로 추천 점수에 추가 가중치를 주되, 자동 관심사 자체를 삭제하거나 덮어쓰지는 않는다.
- 미분류 입력: 표준 테마나 등록된 동의어로 연결되지 않으면 저장하지 않고 가까운 목록 선택을 안내한다.

## 운영 데이터 전환안

1. 기존 2,932개 표현을 별칭표로 표준화한다.
2. 기존 테마와 제목·설명에서 책당 최대 3개를 재분류한다.
3. 자동 변환 결과를 샘플 검수한 뒤 전체 2,048권에 적용한다.
4. 형식·세부 대상·주의 콘텐츠는 삭제하지 말고 후속 별도 필드 마이그레이션 대상으로 보관한다.

v1 목록은 운영 데이터를 다시 분류하기 위한 초안이다. 향후 목록이 바뀌어도 가이드 결과는 재생성하지 않고 추천 분류 데이터만 버전별로 다시 계산한다.
